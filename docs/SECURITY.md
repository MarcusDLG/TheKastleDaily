# Security baseline
Treat NAS as internet-connected. Do not modify existing services or expose DB. API loopback-only until authenticated access design approved. No Docker socket, privileged application containers or host network. Non-root app, dropped capabilities, read-only root. Create least-privilege DB role before adding access; bootstrap role is not for app use. Keep secrets outside Git, restrict file permissions, rotate keys, redact logs. Separate dev and production credentials. External content is untrusted: prevent SSRF, validate redirects and resolved addresses, bound sizes/timeouts, sanitize HTML, isolate instructions from model inputs. Never let article text invoke tools.

Open review items: pin action SHAs and image digests, lock transitive dependencies with hashes, dependency audit, Dependabot and secret scanning, protected main and required CI, approved-release environment reviewers (if supported), restrict package access. Manual approval mandatory. Test encrypted backups and restore, TLS and OAuth scopes, CSRF, audit logs and rate limits. Do not publish or deploy until approved.
